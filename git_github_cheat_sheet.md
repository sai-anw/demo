# *GIT CHEAT SHEET*
 
| Command           | Purpose                | Example                          |
| ----------------- | ---------------------- | -------------------------------- |
| `git init`        | Initialize repository  | `git init`                       |
| `git clone`       | Clone repository       | `git clone <url>`                |
| `git status`      | Check status           | `git status`                     |
| `git add`         | Stage files            | `git add .`                      |
| `git commit`      | Save changes           | `git commit -m "Initial commit"` |
| `git push`        | Push changes           | `git push origin main`           |
| `git pull`        | Pull latest changes    | `git pull origin main`           |
| `git fetch`       | Fetch updates          | `git fetch origin`               |
| `git branch`      | List/Create branches   | `git branch feature`             |
| `git switch`      | Switch branches        | `git switch feature`             |
| `git checkout`    | Checkout branch/file   | `git checkout main`              |
| `git merge`       | Merge branches         | `git merge feature`              |
| `git rebase`      | Reapply commits        | `git rebase main`                |
| `git stash`       | Save uncommitted work  | `git stash`                      |
| `git log`         | View history           | `git log --oneline`              |
| `git diff`        | Compare changes        | `git diff`                       |
| `git reset`       | Unstage/Reset          | `git reset HEAD file.txt`        |
| `git restore`     | Restore file           | `git restore file.txt`           |
| `git revert`      | Revert commit          | `git revert HEAD`                |
| `git tag`         | Create tag             | `git tag v1.0`                   |
| `git remote`      | Manage remotes         | `git remote -v`                  |
| `git cherry-pick` | Apply commit           | `git cherry-pick <hash>`         |
| `git rm`          | Remove file            | `git rm file.txt`                |
| `git mv`          | Rename file            | `git mv old.txt new.txt`         |
| `git clean`       | Remove untracked files | `git clean -fd`                  |
